ARIBA PORTFOLIO — SETUP

Files:
- index.html
- style.css
- script.js

1. Copy these three files into your existing my-portfolio folder, replacing the old files.
2. Keep your profile photo in the same folder and name it exactly: profile.jpg
   If you do not have a photo, the page displays an "A" placeholder.
3. Open index.html with VS Code Live Server.

WHATSAPP CONTACT SETUP:
1. Open script.js.
2. Find: const whatsappNumber = "REPLACE_WITH_NUMBER";
3. Replace REPLACE_WITH_NUMBER with your WhatsApp number including country code,
   digits only (no +, spaces, or dashes). Example format only: 91XXXXXXXXXX
4. Save and test the form. It opens WhatsApp with the message prepared.
5. The visitor must review and press Send in WhatsApp. The website does not send messages silently.

EDIT YOUR DETAILS:
- Change the name and introduction in index.html.
- Update education and project descriptions so they accurately describe your experience.
- Do not publish private information such as home address or personal documents.
